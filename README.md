# Stream overlay

Оверлей для трансляций (табло, таймер, плашка комментатора, рамка вебки) с пультом управления в реальном времени.

- `/overlay` — страница для OBS или Twitch Studio (источник «Браузер», 1920×1080)
- `/control` — пульт, вход по ключу из переменной окружения `CONTROL_KEY`

Запуск локально: `npm install && CONTROL_KEY=ключ npm start`
